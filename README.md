# Роман Гигола — дизайнерское портфолио

[Открыть портфолио](https://tallatril.github.io/roman-gigola-portfolio/) · [Резюме](assets/roman-gigola-cv.pdf) · [Telegram](https://t.me/gigolaroman)

Адаптивное портфолио на русском языке для GitHub Pages: 15 страниц и перенаправление со старой галереи, CSS и небольшой JavaScript для просмотра макетов и фильтрации работ. Сборщик не нужен. Шрифт Manrope хранится локально, лицензия OFL включена.

Содержание: Добро.рф, Fanza Fusion, My Safe Online, шесть проектов Lumex Agency, игровой концепт для Альфа-Банка, Tempick KIDS, примеры UI, опыт и контакты. Визуалы взяты из Figma автора, опубликованных кейсов команды Lumex и сайта NXTarmor. Все права на изображения и бренды принадлежат их владельцам. Источники перечислены в `SOURCES.md`.

## Локальный просмотр

Откройте `index.html` в браузере. Для работы сайта сервер не требуется.

## Публикация

1. Создайте отдельный репозиторий и загрузите в его корень содержимое этой папки. Папки с исходными исследованиями и перепиской загружать не нужно.
2. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации.
3. Отправьте изменения в ветку `main`. Workflow `Publish portfolio to GitHub Pages` подготовит и опубликует сайт.
4. Адрес сайта появится в результате workflow и в настройках Pages.

Настройка основана на [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Редактирование

- `index.html` — короткая главная и карточки проектов.
- `dobro.html`, `pragmacore.html`, `fanza.html`, `mysafe.html` — продуктовые кейсы.
- `nomad.html`, `nxtarmor.html`, `nova.html`, `serene.html`, `omakase.html`, `barber.html` — сайты Lumex Agency.
- `dragon.html`, `tempick.html` — игровой и мобильный интерфейсы Seven Winds Studio.
- `projects.html` — общий каталог 17 проектов с фильтрами.
- `ui.html` — переход со старого адреса в общий каталог.
- `about.html` — опыт, достижения, награды и образование.
- `portfolio.css` — оформление и адаптивы.
- `site.js` — мобильное меню, увеличение и переключение макетов.
- `assets/*.webp` — изображения проектов.
- `assets/roman-gigola-cv.pdf` — резюме для скачивания.
- `DESIGN.md` — визуальные принципы и ссылки на референсы Refero.

Все пути относительные, поэтому сайт работает и на основном адресе GitHub Pages, и в репозитории проекта.

## Проверка перед публикацией

Перед отправкой изменений проверьте страницы на компьютере и телефоне: переходы, изображения, фильтры, мобильное меню, увеличение макетов и раскрытие исследования. Первый блок главной должен целиком помещаться в экран. Ссылки на макеты и разделы исследования доступны и без JavaScript.
